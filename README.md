# Flutter Practica 5

Учебный проект для практической работы №5 «Создание проекта Flutter».

## Что реализовано

- Flutter-приложение на Dart;
- запуск в Chrome через Web-платформу;
- Android-платформа для запуска на эмуляторе или подключённом устройстве;
- простой экран с кнопкой проверки работы приложения;
- базовый widget-тест.

## Запуск

1. Установить Flutter SDK и добавить `flutter/bin` в PATH.
2. Установить Android Studio и Android SDK.
3. Открыть проект в Android Studio.
4. Выполнить `flutter pub get`.
5. Для запуска в браузере выбрать Chrome и нажать Run.
6. Для Android выбрать эмулятор или подключённое устройство и нажать Run.

Проверка проекта:

```bash
flutter analyze
flutter test
```
